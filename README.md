This patch disables SuperWoW's floating healing text.

To apply the patch, drag and drop SuperWoWhook.dll onto this program's .EXE file.

A prebuilt executable can be downloaded from the releases page:  
https://github.com/turtlenips/superwow-patch/releases

SuperWoW version 1.5.1 is required. Get it at:  
https://github.com/balakethelock/SuperWoW
